Every setting is optional. With none, administrators see the API tab on documents and media items.

```json appsettings.json
{
  "DeliveryApiInspector": {
    "Enabled": true,
    "Media": true,
    "UserGroups": []
  }
}
```

| Setting | Default | What it does |
| --- | --- | --- |
| `Enabled` | `true` | Shows the API tab. Turn it off to hide the tab and refuse the package's API on an environment, such as production. |
| `Media` | `true` | Shows the API tab on media items too. |
| `UserGroups` | `[]` | The aliases of the user groups that see the tab. Empty means administrators only. |

The settings are read on every request, so a change to appsettings takes effect without a restart.

## The Delivery API's own settings

The inspector reads the Delivery API's settings to describe the request, and never changes them.

- With `DeliveryApi:Enabled` off, the tab still shows what the API would return, and says that frontends get nothing.
- With `DeliveryApi:PublicAccess` off, or for the draft, the request shows an `Api-Key` header with a placeholder.
- With `DeliveryApi:Media:Enabled` off, the media tab says so.
